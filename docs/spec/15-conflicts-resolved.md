# Conflicts resolved

> Part of the Sodiq School platform spec, baseline of 3 October 2026 (document revision 88).
> Index and reading order: `docs/spec/00-index.md`. Where an edge-case file is more specific than a module file, the edge-case file applies.

Where the sources disagree, the main file wins. Where the main file is silent, the choice follows your message, then the school's own notes, then what works best in myss.uz or the Ziyoly demo.

| Topic | What the sources say | Decision |
| --- | --- | --- |
| Principal's rights | Main file: view only. Ziyoly notes: the director has full rights in the branch. | View only. |
| Roles | Main file: 14 user types. Ziyoly notes: 15 roles. Demo: 16. | The 14 of the main file, plus the Senior Head Teacher added by the school later. New roles can be added in the permission matrix. |
| Languages | Main file: Uzbek, Russian, English. Texnik topshiriq: at least Uzbek and Russian. myss.uz: Uzbek. | All three, complete. |
| Scope | Texnik topshiriq and the Ziyoly demo cover admissions, finance, HR, chat, tasks, gamification. Main file: academics first. | Three releases, academic core first. The rest is listed under Later modules. |
| Mobile apps | Texnik topshiriq requires Android and iOS apps. Main file: web first. | Phone-friendly web from Release 1. Apps in Release 3. |
| Grading weights | Main file: a daily and a quarterly distribution per subject. myss.uz: monthly weights. Ziyoly demo: one fixed formula. Ziyoly notes: weights per quarter. | Daily and quarterly distributions per subject, the quarterly one set for each quarter. |
| Rating exam | myss.uz: a part of the monthly weights. Ziyoly notes and demo: at the end of the quarter. | One score per quarter, rating subjects only. |
| Homework debt | myss.uz and the Ziyoly notes have a debt threshold, a journal column and an analytics page. Your message: not needed. | Removed everywhere. |
| Payment debtors | myss.uz has a debtors page. | Removed. No finance in this system. |
| Grading scale of a work | Ziyoly demo: classwork out of 100, homework out of 15, fixed. myss.uz and your explanation: the teacher sets the total of each work freely. | The teacher sets the total of each work (the number of questions, 5, 100 or any other) and types a number. The system always turns it into a percent. |
| Bonus percent | Ziyoly demo has a bonus column. No school source mentions it. | Not included. |
| Attendance marks | Texnik topshiriq and myss.uz: six marks, 0 to 5. Ziyoly demo: its own set. | The six marks. |
| Teacher statuses | Main file: active, inactive, left. Ziyoly notes add "on leave". | The three of the main file. Leave is recorded in HR in Release 3. |
| Departments | Main file: STEAM, Foreign languages, National, Natural sciences, General, Tutors. Ziyoly notes: "Aniq fanlar" in place of STEAM. | The names of the main file. Departments are editable. |
| Stipend and scholarship | Main file: the quarterly stipend is different from the scholarship. myss.uz has one scholarship page. | Two separate records: scholarship on the profile, stipend awarded per quarter. |
| Building the timetable | Ziyoly demo: a 12-step builder with automatic generation. Texnik topshiriq: manual placing with checks. Your message: generated inside the platform, then edited freely in the grid. | An 8-step builder with auto-generation and full editing in the grid, both in Release 1. |
| Forced delete of a lesson with data | Texnik topshiriq: open to "admin". | Super Admin only, with a reason and a 30-day restore. |
| Lunch | myss.uz uses a "Tushlik" subject to fill a timetable slot. | A labelled break in the lesson times. |
| Academic year | myss.uz shows two active years at once. | Exactly one current year per branch. |
| Lowest grade | myss.uz shows the 0–49 band as 2. | Kept: 2, 3, 4, 5. |
| Student statuses | Main file: active, inactive, graduated, left or archived. Your clarification: inactive and archived both mean the student left the school entirely. | Three statuses: active, inactive (archived, can be brought back), graduated. An exempt student stays active. |
| Lesson plan window | Main file: the Head Teacher assigns the open window for editing. Your message: the Academic Vice Principal sets the window; after it, the Head Teacher approves edits. | The Academic Vice Principal opens the window. After it ends, the Head Teacher of the subject, its Senior Head Teacher, or the Academic Vice Principal approves each edit request. |
