# Later modules

> Part of the Sodiq School platform spec, baseline of 3 October 2026 (document revision 88).
> Index and reading order: `docs/spec/00-index.md`. Where an edge-case file is more specific than a module file, the edge-case file applies.

These are not built in Release 1. The data model leaves room for them, so adding them does not change the academic core. The detailed requirements already exist in the Texnik topshiriq and are reused when each module starts.

| Module | Release | Role | Scope in one line | Texnik topshiriq |
| --- | --- | --- | --- | --- |
| Announcements and events | 2 | Management | News and events for chosen audiences, with a calendar. | 4.11 |
| HR | 3 | HR | Staff records, contracts, leave, documents, staff attendance. | 4.5 |
| Medical | 3 | Nurse | Health profile, visits to the nurse, medicines, first aid records. Exemptions stay with the Academic Vice Principal. | 4.12 |
| Psychologist | 3 | Psychologist | Sessions and diagnostics, closed to all other roles. | 4.13 |
| Library | 3 | Librarian | Catalogue, lending, returns, overdue list. | 7.5 |
| Mobile apps | 3 | All | Android and iOS apps for teachers, students and parents with push messages. | 10 |
| TestBor and Mock24 | 3 | Academic Vice Principal | Import of exam results into rating exam scores. | 7.2 |

The HR, Nurse, Psychologist and Librarian roles are in the permission matrix from Release 1, so their accounts are switched on when each module is ready, with no change to the rest of the system.
