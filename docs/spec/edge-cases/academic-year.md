# Edge cases: academic year

> Part of the Sodiq School platform spec, baseline of 3 October 2026 (document revision 88).
> Index and reading order: `docs/spec/00-index.md`. Where an edge-case file is more specific than a module file, the edge-case file applies.

| Case | Rule |
| --- | --- |
| Someone creates classes before an academic year exists, or a day template before slot types. | Each branch has a setup checklist in a fixed order: branch and working weekdays, rooms, departments, year, four quarters, slot types, default template, calendar, subjects and weights, staff with subjects and availability, classes, students, groups, teaching load, timetable. An action whose prerequisite is missing is switched off and says what is missing. |
| The timetable is published on 1 September while a subject has no weights. | Publishing is blocked unless the year has four dated quarters and every subject in the load has its journal type and, if it is graded, its daily distribution and its quarterly distribution for each quarter the version touches. Attendance-only subjects need no weights. |
| In August the school must prepare next year while this year's corrections continue. | A "planned" year and the "current" year both accept setup and timetable publishing; journals take entries by each lesson's own date. The top bar labels a planned year. "Start year" is one action by the Super Admin, available only after "Close the year" was carried out for the previous year; it makes the planned year current. |
| Quarter 4 is closed. What produces year results and graduation? | "Close the year" is its own checklist action and needs four closed quarters. It stores the year result for every student and subject, with the class grade and name, subject name and teacher as they were. Graduation and rollover need the year closed. |
| Rollover is started in June, abandoned, and run again in August after students left, two must repeat a grade and a class is dissolved. | Rollover is a saved plan per branch that can be edited until it is carried out. It is carried out once, in one step; a second attempt only shows the plan. For each class: promote, merge, split or discontinue; grade 11 graduates. For each student: promote by default, or repeat, another class, leave, not graduating. It can be undone until a lesson of the new year holds data. |
| What does rollover copy? | Copied as drafts to confirm: Tutor and room of each class, teaching load (rows whose teacher lacks the new grade are flagged), subject weights for the new quarters, master plans, and group definitions, either empty or with their members. Not copied: exemptions and lesson plans of classes. |
| A class or subject is renamed, and last year's results are printed afterwards. | Live pages show current names. Closed quarters and years keep the names as they were, and prints of closed periods use those. |
| An old timetable version with an archived teacher and a closed room is copied as a draft. | Entries whose teacher, room, subject or class is no longer active go to the "to place" list with the reason. |
| The class name "7 Oxford" is used again the next year; an archived relative returns with the same phone. | Phones, document numbers, UIDs and staff IDs are unique including archived records, and adding one that exists offers "restore". A class name is unique within a branch, grade and year, so the same name can be used again in another year or grade. Group names are unique per branch and year. |
| The school goes live in the middle of the year, or in the middle of a quarter. | Go-live can be on any school day. The Super Admin sets a start date for each branch. No dated lessons exist before it, and the first timetable version starts on it. **Start quarter.** The quarter that contains the start date is calculated from the lessons from the start date on. Its result is labelled "from" with the date, on screen, in prints and in exports. The few-lessons flag counts only lessons from the start date, so it is not raised for everybody. **Closing the start quarter.** The Academic Vice Principal chooses one option for the whole branch: keep the platform results as the quarter results, or mark the quarter "not official". A "not official" quarter is left out of the year result and its official results are produced the old way. **Earlier quarters.** Quarters that ended before the start date are marked "not in the system" and left out of the year result, which is labelled "based on n of 4 quarters". **Journals and plans.** The first lesson of each journal after the start date has no homework column. The plan window is opened before the start date, and plans cover the lessons from the start date. A plan in the start quarter begins at a lesson number typed by the teacher, 1 by default. |
| The pilot grade's teachers also teach other grades. | In the pilot the whole branch's timetable is loaded, so clashes are real, but only the pilot grade uses journals. The present way of working stays the official record until a written decision to switch. Before the switch, one full quarter of two or three real journals is entered and compared. |
