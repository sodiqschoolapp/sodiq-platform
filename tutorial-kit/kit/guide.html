Things to know

  • Every person and phone is invented. Phones are +998 97 1xx for staff and +998 93/94 for parents, away from the demo seed’s numbers.
  • The files were checked with the platform’s own reader. Checks that need the live database (the one-department rule, class placement, phones already held) run when you press Save; they should pass, and the preview names any row that does not.
  • 6 Imperial: its real grade-6 Matematika and English blocks are not built, so they are whole-class rows. Say so on camera.
  • 3 Indigo is entered as a Russian-language class because its sheet has Oʻzbek tili. If it is not, set its language to Uzbek; nothing else changes.
  • After the rehearsal, run step A1 again: it wipes the branch and you start the real take from step 1.
